CSS GridDesign System

Northbeam — Analytics Dashboard

What they neededA dashboard where widgets of different sizes could be rearranged by users without the grid breaking or leaving gaps.

Built the layout on CSS Grid with named template areas, so each widget occupies a defined region and resizes independently while the row heights stay aligned.

View code 
.dashboard {
  display: grid;
  grid-template-columns: repeat(6, 1fr);
  grid-template-areas:
    "kpi  kpi  kpi  chart chart chart"
    "list list activity activity map map";
  gap: 20px;
}
.widget-kpi   { grid-area: kpi; }
.widget-chart { grid-area: chart; }
.widget-map   { grid-area: map; min-height: 260px; }
Flexbox

Loop Cards

What they neededA card component that stayed aligned however much text or how many tags each card had.

Used a column flex container with a flexed body and a footer pinned to the bottom, so card heights match automatically in any grid.

View code 
.card {
  display: flex;
  flex-direction: column;
  height: 100%;
}
.card__body { flex: 1 1 auto; }
.card__footer {
  margin-top: auto;
  display: flex;
  justify-content: space-between;
}
Dark modeCustom properties

Theme Engine

What they neededOne light/dark toggle that could restyle three separate product lines without duplicating CSS.

Centralised every color, radius and shadow into CSS custom properties scoped to a data-theme attribute, swapped in a single line of JS.

View code 
[data-theme="dark"] {
  --bg: #0E1116;
  --ink: #EDEFF2;
  --accent: #7C93FF;
}
btn.addEventListener('click', () => {
  const t = root.dataset.theme;
  root.dataset.theme = t === 'dark' ? 'light' : 'dark';
});

TableTime — Restaurant Booking Widget

What they neededAn embeddable slot-picker that showed a full week of availability without horizontal scrolling on mobile.

Rendered days as CSS Grid columns on desktop, then collapsed to a single scrollable column with sticky day headers below 560px.

View code 
.slots {
  display: grid;
  grid-template-columns: repeat(7, 1fr);
  gap: 8px;
}
@media (max-width: 560px) {
  .slots { grid-template-columns: 1fr; }
  .slots .day-head { position: sticky; top: 0; }
}
ResponsiveMobile-first

Ferry & Co — Commerce Site

What they neededA legacy fixed-width storefront rebuilt to work on phones, since 60% of traffic was mobile and the old layout broke below 768px.

Rewrote the CSS mobile-first: base styles target a single column, with min-width media queries layering on the grid as screen space grows.

View code 
.product-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}
@media (min-width: 640px) {
  .product-grid { grid-template-columns: repeat(2, 1fr); }
}
@media (min-width: 1024px) {
  .product-grid { grid-template-columns: repeat(4, 1fr); }
}
